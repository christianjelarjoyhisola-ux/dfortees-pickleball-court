# D'fortees Pickleball Court Changelog

## 2026-07-16 — Isolated D'fortees foundation

- Created a fresh local Git history with no remote connection.
- Removed all live Supabase URLs, JWT-shaped browser keys, legacy domains, advertising IDs, and Korte runtime branding.
- Added a safe-by-default local data mode that blocks backend requests until the new D'fortees backend is configured.
- Added a centralized brand configuration and modern responsive visual system.
- Reworked the booking landing experience, removed the splash-screen tap gate, and improved keyboard focus and reduced-motion support.
- Rebranded the customer, host, login, admin, email, receipt-verification, database, and notification surfaces.
- Restricted the Cloudflare runtime package to public application assets only.
- Added explicit deployment target guards and disabled automatic database pushes.
- Added repeatable fresh-database bundle generation and automated project verification.
- Verified desktop and mobile booking layouts, slot selection, booking form opening, local staff login, admin dashboard rendering, and host application navigation.
